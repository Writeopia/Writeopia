# Command Samples

Writeopia handles many text commands that create new content from what the user types. The built-in commands are
listed in **Default Commands**; this page shows what they produce.

## Checkbox

Typing `-[]` creates a checkbox in place of the current message.

![checkbox sample](../../../static/img/checkbox_sample.gif)

It changes the type of the step to `StoryTypes.CHECK_ITEM` through
[WriteopiaManager.changeStoryType](https://javadoc.io/doc/io.writeopia/writeopia-core/latest/io/writeopia/sdk/manager/-writeopia-manager/index.html).

## List item

Typing `- ` creates a list item in place of the current message.

![list item sample](../../../static/img/list_item_sample.gif)

It changes the type to `StoryTypes.UNORDERED_LIST_ITEM`.

## H1, H2, H3, H4

Headers are `message` steps with a tag, not types of their own.

| Command | Result |
| ------- | ------ |
| `# ` | H1 |
| `## ` | H2 |
| `### ` | H3 |
| `#### ` | H4 |

## Code block and divider

| Command | Result |
| ------- | ------ |
| ```` ``` ```` | `StoryTypes.CODE_BLOCK` |
| `---` | `StoryTypes.DIVIDER` |

## Highlight and card blocks

`/box` turns the message into a highlighted block and `/card` into a card block. Both are `Tag`s on a `message`, so the
type of the step does not change.
