# Persistence

![Maven Central](https://img.shields.io/maven-central/v/io.writeopia/writeopia-persistence-core)

The persistence plugin saves documents locally. Add the plugin for your platform:

```kotlin
// Android: the application uses Room
implementation("io.writeopia:writeopia-persistence-room:[version]")
// Desktop, iOS, Web: SQLDelight
implementation("io.writeopia:writeopia-persistence-sqldelight:[version]")
```

Both platforms share the contracts in `io.writeopia:writeopia-persistence-core:[version]`, which is pulled in
transitively. The examples below use the Room implementation.

## Configuration

To configure persistence you need:

- a Room database that declares the SDK entities and DAOs;
- a `RoomDocumentRepository` over that database;
- the repository passed to `WriteopiaStateManager.create`;
- a `UserRepository`, so saved documents keep the workspace they belong to.

### Creating a Room database for Writeopia

The persistence plugin provides the entries and DAOs; your application database adds them to its own. The application
module needs Room itself, since the plugin declares it as `implementation` and configures its compiler only for its own
module:

```kotlin
// Android: Room for the application's own database
implementation("androidx.room:room-runtime:2.8.4")
ksp("androidx.room:room-compiler:2.8.4")
```

Apply the `com.google.devtools.ksp` plugin to the module too.

```kotlin
@Database(
    entities = [
        DocumentEntity::class,
        StoryStepEntity::class,
        StoryStepTombstoneEntity::class,
        PendingFavoriteEntity::class,
        CommentEntity::class,
        DocumentTagLinkEntity::class,
        // Your own entities here
    ],
    version = 1,
    exportSchema = false
)
@TypeConverters(IdListConverter::class)
abstract class WriteopiaApplicationDatabase : RoomDatabase() {

    abstract fun documentDao(): DocumentEntityDao
    abstract fun storyUnitDao(): StoryUnitEntityDao
    abstract fun storyStepTombstoneDao(): StoryStepTombstoneDao
    abstract fun pendingFavoriteDao(): PendingFavoriteDao
    abstract fun commentDao(): CommentEntityDao
    abstract fun documentTagLinkDao(): DocumentTagLinkDao
}
```

### Building the repository

Build the database first, then pass its DAOs and the database itself to `RoomDocumentRepository`:

```kotlin
val database = Room.databaseBuilder(
    context,
    WriteopiaApplicationDatabase::class.java,
    "writeopia.db",
).build()

val repository = RoomDocumentRepository(
    documentEntityDao = database.documentDao(),
    storyUnitEntityDao = database.storyUnitDao(),
    commentEntityDao = database.commentDao(),
    database = database,
    documentTagLinkDao = database.documentTagLinkDao(),
    storyStepTombstoneDao = database.storyStepTombstoneDao(),
    pendingFavoriteDao = database.pendingFavoriteDao(),
)
```

## Reading and saving documents

Pass the repository to `WriteopiaStateManager.create`:

```kotlin
val stateManager = remember {
    WriteopiaStateManager.create(
        writeopiaManager = WriteopiaManager(),
        dispatcher = Dispatchers.IO,
        documentRepository = repository,
        userRepository = userRepository,
    )
}
```

`userRepository` supplies the workspace ID that `saveOnStoryChanges` writes with each document. Without it the tracker
saves the disconnected workspace, so an online document leaves its workspace as soon as it is edited: omit it only for
documents that never leave the device.

With a repository in place the editor can load documents and create linked documents.

## Saving as the user types

`WriteopiaStateManager.saveOnStoryChanges` starts an endless collector that writes every edit through a
`DocumentTracker`. `RoomDocumentRepository` implements `DocumentUpdate`, so `OnUpdateDocumentTracker` can persist to
the database directly:

```kotlin
LaunchedEffect(Unit) {
    stateManager.saveOnStoryChanges(
        OnUpdateDocumentTracker(documentUpdate = repository)
    )
}
```

The tracker also accepts `onStoryStepUpdate` and `onDocumentUpdate` callbacks, which the application uses to feed a
full-text search index.
