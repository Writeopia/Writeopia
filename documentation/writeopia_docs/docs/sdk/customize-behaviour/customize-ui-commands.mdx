# UI Commands

The entry point for the editor's state and behaviour is `WriteopiaStateManager`. It owns the story, the cursor, the
selection and the back stack, and it is what you pass around instead of the `WriteopiaManager` underneath it.
`WriteopiaManager` stays the logic layer: it transforms `StoryState` and knows nothing about Compose.

In this section you will learn the behaviour the default drawers provide and how to reuse it in your own drawers.

## Swipe to Edit

One way to edit messages, checkboxes, images and the other types is to swipe horizontally to select the content.

![swipe to edit sample](../../../static/img/swipe_to_edit.gif)

`SwipeBox` implements it: it colours the row, draws the selection border and calls `swipeListener` with the new
selected state.

```kotlin
SwipeBox(
    modifier = Modifier.fillMaxWidth(),
    isOnEditState = drawInfo.selectMode,
    activeColor = MaterialTheme.colorScheme.surfaceVariant,
    swipeListener = { selected -> manager.onSelected(selected, drawInfo.position) },
) {
    Text(step.text.orEmpty())
}
```

## Drag and Drop

Content is moved with the drag icon on the right side of a step. The default drawers wrap the row in `DragRowTarget`
(`DragCardTarget` for card-shaped content), both of which come from `io.writeopia.ui.draganddrop.target`.

`DesktopTextItemDrawer` already wires the drag icon, the drop target, external file drops and the swipe box around a
`SimpleTextDrawer`. Use it instead of reimplementing the behaviour; see **Editing Drawers**.

## Backstack

Writeopia comes with a default implementation of the back stack, `SnapshotBackstackManager`, which allows the user to
undo and redo. `WriteopiaStateManager` implements `BackstackHandler` and `BackstackInform`, so you call
`stateManager.undo()` and `stateManager.redo()` and read `canUndo` / `canRedo` from it.

![backstack sample](../../../static/img/backstack_sample.gif)

To change the behaviour, pass your own manager to `WriteopiaStateManager.create`:

```kotlin
WriteopiaStateManager.create(
    writeopiaManager = WriteopiaManager(),
    backStackManager = SnapshotBackstackManager(textEditLimit = 20),
)
```
