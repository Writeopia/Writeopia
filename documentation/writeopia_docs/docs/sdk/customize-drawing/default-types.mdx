# Default Types

`StoryTypes` lists the types the SDK knows about. The number is what persists in the database and what the `drawers`
map of `WriteopiaEditor` is keyed by.

| Type name | Number | Description |
| --------- | ------ | ----------- |
| `message` | 0 | A text message with one or multiple lines |
| `message_box` | 1 | A message drawn on a background colour, from `StoryStep.decoration` |
| `image` | 2 | An image |
| `group_image` | 3 | A row of one or more images |
| `audio` | 4 | An audio file. The SDK has no default drawer for it yet |
| `group_video` | 5 | A group of videos. The SDK has no default drawer for it yet |
| `video` | 6 | A video preview. Drawn on Android and Desktop |
| `space` | 7 | A blank space that separates content; other steps can be dropped into it |
| `last_space` | 8 | The blank space at the end of the document |
| `add_button` | 9 | A button with an add action |
| `check_item` | 10 | A message with a checkbox |
| `title` | 11 | The title of a document |
| `unordered_list_item` | 16 | A list item without order |
| `on_drag_space` | 17 | A drop placeholder shown while dragging |
| `ai_answer` | 18 | A text generated by the AI, with accept and regenerate actions |
| `loading` | 19 | A spinner |
| `document_link` | 20 | A link to another document |
| `divider` | 21 | A horizontal line |
| `equation` | 22 | A LaTeX equation |
| `code_block` | 23 | A code block with its own text style |
| `link_card` | 24 | A card for a web link |
| `skeleton` | 25 | A placeholder shown while AI rewrites a step |
| `drawing` | 100 | A freehand drawing; the application supplies its drawer |
| `spreadsheet` | 101 | A table |
| `spreadsheet_row` | 102 | A row of a table |
| `spreadsheet_cell` | 103 | A cell of a table |

H1, H2, H3 and H4 are not types: they are `Tag`s on a `message`, set by the commands described in the **Commands**
section.

Each type is mapped to a `StoryStepDrawer`. The next section lists the drawers the default factories provide.
