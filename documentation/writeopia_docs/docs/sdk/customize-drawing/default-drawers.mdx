# Default Drawers

The SDK comes with a drawer for almost every default type. `DefaultDrawersAndroid`, `DefaultDrawersDesktop`,
`DefaultDrawersJs` and `DefaultDrawersNative` build the map for you; the shared part lives in `CommonDrawers`.

| Type | Drawer | What it draws |
| ---- | ------ | ------------- |
| `message` | `TextDrawer` behind `swipeTextDrawer` | Editable text with swipe to select |
| `message_box` | `DesktopTextItemDrawer` with the colour of `StoryStep.decoration` | Editable text on a background |
| `check_item` | `DesktopTextItemDrawer` with a checkbox | Editable text with a checkbox |
| `unordered_list_item` | `DesktopTextItemDrawer` with a dash | Editable text with a bullet |
| `title` | `HeaderDrawer` | The document title; also draws the H1–H4 tags |
| `code_block` | `CodeBlockDrawer` | Monospaced text on a coloured background |
| `divider` | `DividerDrawer` | A horizontal line |
| `image` | `ImageDrawer` | A single image |
| `group_image` | `RowGroupDrawer` | A row of images |
| `link_card` | `LinkCardDrawer` | A web link preview |
| `document_link` | `DocumentLinkDrawer` | A link to another document |
| `equation` | `EquationDrawer` | A rendered LaTeX equation |
| `spreadsheet` | `SpreadsheetDrawer` | A table with add, delete and move actions |
| `ai_answer` | `AiAnswerDrawer` | Generated text with accept and regenerate |
| `skeleton` | `SkeletonDrawer` | Placeholder while AI rewrites a step |
| `loading` | `LoadingDrawer` | A spinner |
| `space` | `SpaceDrawer` | A drop target between steps |
| `on_drag_space` | `SpaceDrawer` | The placeholder shown while dragging |
| `last_space` | `LastEmptySpace` | The tappable area after the last step |
| `add_button` | `AddButtonDrawer` | A button that adds a step |
| `video` | `VideoDrawer` | A video preview; Android and Desktop only |
| `drawing` | supplied by the application | A freehand drawing |

`SimpleTextDrawer` is the interface behind the text drawers. `TextDrawer` is its editable implementation; the preview
drawers under `io.writeopia.ui.drawer.preview` are read-only implementations of the same interface.
