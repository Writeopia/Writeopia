# API reference

The KDoc of every public declaration is published with each artefact on
[javadoc.io](https://javadoc.io/doc/io.writeopia).

## Core components

- [Writeopia Models](https://javadoc.io/doc/io.writeopia/writeopia-models/latest/index.html) — `StoryStep`,
  `StoryType`, `StoryTypes`, `Document`, spans, tags and commands.
- [Writeopia Core](https://javadoc.io/doc/io.writeopia/writeopia-core/latest/index.html) — `WriteopiaManager`, the
  managers that transform a `StoryState`, repositories and trackers.
- [Writeopia UI](https://javadoc.io/doc/io.writeopia/writeopia-ui/latest/index.html) — `WriteopiaEditor`,
  `WriteopiaStateManager`, `DrawConfig`, `StoryStepDrawer` and the default drawers.
